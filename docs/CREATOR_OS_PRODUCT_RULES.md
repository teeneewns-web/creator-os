# Creator OS — Current Product Rules

เอกสารนี้คือทิศทางปัจจุบันของ Creator OS ให้ยึดเหนือแนวคิดหรือโค้ดเก่าที่ขัดแย้งกัน

## 1. สินค้าหลัก

Creator OS ส่งมอบแผนคอนเทนต์ 7 วันเฉพาะผู้ใช้ จากข้อมูลจริงของผู้ใช้ ไม่ใช่คลังไอเดียสุ่มหรือคำแนะนำกว้าง ๆ

แผนต้องพร้อมนำไปทำและโพสต์ได้จริง โดยคำนึงถึงสินค้า/บริการ/แนวครีเอเตอร์ เป้าหมาย แพลตฟอร์ม กลุ่มผู้ชม เวลา ความสามารถ และข้อจำกัด

## 2. เส้นทางผู้ใช้

`/start` → `/checkout` → `/order/[orderId]` → `/admin/orders` → Quality Gate → `/dashboard/weekly`

แผนต้องไม่เปิดให้ลูกค้าก่อนผู้ดูแลอนุมัติและ Quality Gate ผ่านอย่างน้อย 85/100 โดยไม่มีจุดปิดกั้น

## 3. การกำหนดทิศทางคอนเทนต์

ผู้ใช้ต้องเลือกประเภทแผนก่อน ได้แก่ สินค้า บริการ หรือครีเอเตอร์ แล้วระบบจึงแสดงตัวเลือกทิศทางที่เกี่ยวข้องเท่านั้น

ทิศทางคอนเทนต์เป็นตัวเลือกที่ระบบกำหนด ไม่ใช้ช่องข้อความอิสระเพียงอย่างเดียว เพราะเป็นข้อมูลหลักที่ควบคุมรูปแบบแผน

ข้อความอิสระยังใช้เก็บรายละเอียดเฉพาะของผู้ใช้ เช่น จุดเด่น สิ่งที่ผู้ชมคาดหวัง และข้อจำกัด

## 4. ข้อมูลครีเอเตอร์ต้องแยกสองความหมาย

- สิ่งที่ผู้ชมชอบหรือคาดหวัง: ใช้กำหนดสิ่งที่ผลงานควรส่งมอบให้ผู้ชม
- ปัญหาที่ผู้สร้างต้องการให้ Creator OS ช่วย: ใช้กำหนดสิ่งที่ระบบต้องทำแทนผู้สร้าง

ห้ามนำปัญหาของผู้สร้างไปเขียนเป็นปัญหาของผู้ชม ตัวอย่าง: “คิดบทไม่ได้” ต้องทำให้ระบบสร้างบทพร้อมถ่าย ไม่ใช่สร้างคลิปสอนผู้ชมคิดบท

## 5. มาตรฐานแผนครีเอเตอร์บันเทิง

เมื่อเลือกหนังสั้น ละครสั้น หรือตลก แกนหลักต้องเป็นผลงานให้ผู้ชมดู ไม่ใช่คอนเทนต์สอนการทำผลงาน เว้นแต่ผู้ใช้เลือกทิศทางให้ความรู้เอง

แผนหนังสั้นควรมีชื่อเรื่อง แนวคิด ตัวละคร บทแบ่งฉาก บทพูด ลำดับภาพ ข้อความบนจอ จังหวะเสียง ตอนจบ แคปชัน CTA และแผนสำรองพร้อมถ่าย

## 6. ภารกิจ Facebook

ภารกิจที่ Creator OS คำนวณให้ต้องอิงแผนจริง เวลา และความสามารถของผู้ใช้ แก้ไขไม่ได้ และไม่ควรกำหนดงานผลิตหลักเกินหนึ่งชิ้นต่อวัน

ภารกิจเพิ่มเติมที่ผู้ใช้ต้องการทำเองต้องแยกเป็นอีกส่วนหนึ่งและแก้ไขได้ ห้ามใช้ตัวเลขตัวอย่างตายตัวเป็นคำแนะนำหลักของระบบ

## 7. Quality Gate

Quality Gate ต้องตรวจทั้งความครบถ้วนและความตรงกับเจตนา หากทิศทางแผนไม่ตรงกับทิศทางที่ผู้ใช้เลือก ให้ถือเป็นข้อผิดพลาดสำคัญและห้ามเปิดแผน

## 8. สิ่งที่ยกเลิกแล้ว

AI Creator / Content Creator รุ่นเก่าและเส้นทางเก่าที่ขัดกับ Creator OS ปัจจุบันถือว่ายกเลิก ห้ามนำกลับมาใช้โดยอัตโนมัติ


## 9. หลัก Controlled Core + Free Facts

ข้อมูลที่มีผลต่อทิศทางแผนต้องเป็นตัวเลือกมาตรฐานของระบบ เพื่อให้การสร้างแผนและ Quality Gate ตรวจได้แน่นอน ได้แก่:

- ประเภทแผน
- ทิศทางคอนเทนต์หลัก
- ระดับความคุ้นเคยของผู้ชม
- สิ่งหลักที่ผู้ชมควรได้รับ
- เป้าหมายหลัก
- สิ่งที่อยากให้ผู้ชมทำต่อ
- ส่วนที่ต้องการให้ Creator OS ช่วย
- น้ำเสียง
- แพลตฟอร์ม เวลา และความสามารถ

ช่องข้อความอิสระใช้เฉพาะข้อเท็จจริงเฉพาะตัวที่ระบบไม่ควรเดาหรือกำหนดแทน ได้แก่:

- ชื่อสินค้า บริการ หัวข้อ หรือผลงาน
- จุดเด่น หลักฐาน ทรัพยากร และรายละเอียดจริง
- รายละเอียดกลุ่มเป้าหมาย
- ราคา โปรโมชั่น พื้นที่ และช่องทางสั่งซื้อ
- ข้อห้าม ข้อจำกัด และข้อมูลที่ไม่ควรเปิดเผย

หากลูกค้าไม่พบตัวเลือกทิศทางที่ตรง ห้ามบังคับให้เลือกตัวเลือกใกล้เคียงเพื่อสร้างแผนทันที ต้องมีช่องทางแจ้งขอเพิ่มแนวทาง และตรวจว่าควรเพิ่มเป็นมาตรฐานหรือรับเป็นงานเฉพาะก่อนขาย
